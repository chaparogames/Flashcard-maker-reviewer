# Flashcard Maker & Reviewer

A simple Python project for creating and reviewing flashcards. Designed to help users study and memorize information efficiently. Nearly portable to the web, current version (appintheworks.py) has an issue with how card logic is taken and the "# Study Page" features are still being developed. Pushing to git for possible need to revert to previous files.

## Features
- Create custom flashcards
- Review flashcards interactively
- Easy-to-use interface
- Nearly portable to the web (Issues with Study feature)

## Usage
1. Run `main.py` to start the application in terminal.
2. Follow prompts to create or review flashcards.

## Requirements
- Python 3.x
- Install dependencies: `pip install -r requirements.txt`

## Project Structure
- `Flashcard_Creation.py`: Handles flashcard creation logic
- `main.py`: Main entry point for the app
- `requirements.txt`: Python dependencies
- `appintheworks`: Under development streamlit version
